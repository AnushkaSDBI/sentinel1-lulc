# Results

Small result files copied from the run folders on Data Lab by `scripts/collect_results.py`: training histories, model cards, configs,
evaluation metrics, per-region scores, boundary and false-change tables. No weights (`*.pt`) are stored here.

- `runs/`: models trained on 2021 only (V0 to V12) and their evaluations.
- `runs_multiyear/`: models trained on 2021 to 2024 and their evaluations on 2025 and 2026.
- `tables/`: tables written by `notebooks/report_stats.ipynb`.
- `report_numbers.md`: every number of the report in one file, generated by the notebook. Do not edit it by hand.
